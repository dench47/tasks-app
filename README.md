# tasks-app: страница задач с фильтром по приоритету

Тестовое задание: React + TypeScript, Vite, без бэкенда (моковые данные).

## Демо

Живая страница (Vercel): https://tasks-app-jade-kappa.vercel.app/
Зеркало (GitHub Pages): https://dench47.github.io/tasks-app/

## Запуск локально

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build    # проверка типов (tsc -b) + production-сборка в dist/
npm run preview  # локальный просмотр собранной версии
```

## Архитектура

Слои разделены по одному принципу: компоненты не знают, откуда приходят данные.

```
src/
  types.ts              доменные типы: Task, TaskDraft, Priority
  data/mock.ts          моковые данные вместо бэкенда
  hooks/useTasks.ts     состояние экрана: список, фильтр, добавление
  components/           презентационные компоненты
    TaskFilter.tsx        фильтр (управляемый, без собственного состояния)
    TaskList.tsx          список + пустое состояние
    TaskItem.tsx          строка задачи (memo)
    CreateTaskModal.tsx   модальное окно создания
```

Замена моковых данных на реальный API затрагивает один файл (`mock.ts`) и один хук (`useTasks`). Компоненты при этом не меняются.

## Решения и почему

- Нативный `<dialog>` вместо библиотеки модалок: Escape, фокус-ловушка и доступность из коробки. Зависимостей ноль.
- Состоянием открытия модалки управляет родитель (App), а нативный элемент синхронизируется с React-состоянием эффектом. Единственный источник истины: React.
- Нативное закрытие по Escape перехватывается (`preventDefault` на событии `cancel`), чтобы `<dialog>` не разошёлся с состоянием приложения.
- Фильтр это производное состояние: `useMemo` пересчитывает видимый список только при смене задач или фильтра. Отдельной копии отфильтрованного списка в стейте нет.
- Строки списка обёрнуты в `memo`, действия в хуке стабилизированы `useCallback`: ввод в модалке не перерисовывает весь список.
- Ключи списка по `id` задачи, новые задачи получают `crypto.randomUUID()`.
- Форма: нативная валидация (`required`, `maxLength`) плюс обрезка пробелов; кнопка «Создать» заблокирована при пустом названии.
- Время хранится в ISO 8601, форматирование через `Intl.DateTimeFormat` только на выводе: логика не зависит от локали.
- Строгий TypeScript (`strict`, `noUnusedLocals`, `verbatimModuleSyntax`), ни одного `any`.
- Сборка Vite 7 с `base: './'`: `dist` работает и на GitHub Pages (в подпапке), и на любом статическом хостинге. Деплой автоматизирован через GitHub Actions (`.github/workflows/deploy.yml`).
